Local Installation Guide

Clone and run NexCart in under 2 minutes.

# 1. Clone the repository
git clone https://github.com/avipatel2004/NexCart-EcommerceWebsite.git
cd NexCart-EcommerceWebsite

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Run database migrations & start server
python NexCart/manage.py migrate
python NexCart/manage.py runserver
